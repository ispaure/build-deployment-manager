# Build Deployment Manager

The manager turns a project's declared checks, builds and deliveries into a plan
you can review, execute and inspect. The project supplies the commands and release
rules; the manager supervises them and keeps their evidence.

the contracts behind them. Dated audits and UX briefs record earlier work; use
the current guides and source when implementing a change.
